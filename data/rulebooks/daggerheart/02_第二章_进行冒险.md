

# 第二章：进行冒险

本章为玩家提供完整的游戏规则，包括核心机制、战斗、休整、装备、升级、死亡等全部内容。

---

## 游戏流程

### 核心循环（五步）

```
第1步：GM叙述细节 → 第2步：玩家和GM提问 → 第3步：回答问题 → 第4步：选择并结算行动 → 第5步：循环往复
```

### 聚焦 (Focus)

- 当前主导场景的角色处于"聚焦"状态。
- 聚焦自然流转，但GM可在恐惧结果时聚焦敌人。
- 鼓励所有玩家轮流获得聚焦机会。

### 你的回合

- 无固定回合顺序，无固定动作次数。
- 遵循剧情自然流动。
- 可选工具：**聚焦追踪器**（每角色可设3次动作，用完则轮换）。

## 核心机制

### 二元骰

| 骰子 | 代表 | 效果 |
|------|------|------|
| 希望骰 | 命运眷顾 | 点数高 → 获得1希望点 |
| 恐惧骰 | 命运对抗 | 点数高 → GM获得1恐惧点 |
| 关键成功 | 两骰点数相同 | 必定成功 + 获得希望点 + 清除1压力 |

**关键成功额外效果**：攻击时造成额外伤害（取伤害骰最大值再加正常掷骰）。

### 希望点的使用

| 用途 | 花费 | 效果 |
|------|------|------|
| 帮助盟友 | 1 | 掷d6优势骰加入盟友掷骰 |
| 使用经历 | 1/每项 | 将经历加值加入掷骰 |
| 接力掷骰 | 3 | 与另一角色合力行动，选择最优骰结果 |
| 希望特性 | 3 | 激活职业独特能力 |

### 恐惧点

- 玩家掷出恐惧结果时，GM获得1恐惧点。
- GM可花费恐惧点：打断行动、额外行动、使用敌人/环境恐惧特性、添加敌人经历加值。
- 恐惧点上限12，可在场次间保留。

## 动作掷骰

### 四步流程

```
步骤1: 选择角色属性（由GM根据行动描述指定）
步骤2: 添加额外骰子和调整值（经历、优势/劣势骰、特性等）
步骤3: 掷骰（二元骰 + 额外骰子）
步骤4: 结算结果（比较总值与难度，判定成败及希望/恐惧）
```

### 掷骰结果总表

| 结果类型 | 条件 | 效果 |
|----------|------|------|
| 关键成功 | 两骰点数相同 | 必定成功 + 1希望点 + 清除1压力 + 额外伤害（攻击时） |
| 希望成功 | 希望骰>恐惧骰 且 总值≥难度 | 成功 + 1希望点 |
| 恐惧成功 | 恐惧骰>希望骰 且 总值≥难度 | 成功 + GM获1恐惧点 + 引入代价/复杂情况 |
| 希望失败 | 希望骰>恐惧骰 且 总值<难度 | 失败 + 1希望点 + 轻度后果 |
| 恐惧失败 | 恐惧骰>希望骰 且 总值<难度 | 失败 + GM获1恐惧点 + 严重复杂情况 |

### 难度设定

| 难度值 | 描述 |
|--------|------|
| 5 | 非常简单 |
| 10 | 简单 |
| 15 | 普通 |
| 20 | 困难 |
| 25 | 非常困难 |
| 30 | 几乎不可能 |

### 特殊动作掷骰

**属性掷骰**：使用特定属性的动作掷骰，如"敏捷掷骰（12）"。

**攻击掷骰**：使用武器或法术的攻击，成功则进行伤害掷骰。

**施法掷骰**：使用施法属性创造魔法效果，有固定难度或对抗目标难度。

**团队动作掷骰**：多人协作时，领导者掷骰，其他成员反应掷骰，成功/失败给予领导者±1加值。

**接力掷骰**：花费3希望点与另一角色合力，各掷骰后选择其一作为共同结果。攻击时可分别掷伤害并相加。

## 伤害掷骰

### 熟练值

- 初始1级熟练值为1，最高可升至6。
- 熟练值决定武器攻击时掷出的伤害骰数量。

### 伤害计算

- 伤害掷骰 = 熟练值个数的伤害骰 + 调整值。
- 例：熟练值2，武器d8 → 掷2d8 + 调整值。

### 伤害类型

| 类型 | 说明 |
|------|------|
| 物理伤害 | 普通物理打击（刀剑、弓箭等） |
| 魔法伤害 | 通过魔法手段造成（法术、魔法武器等） |
| 直接伤害 | 无法通过护甲槽降低的伤害（中毒等） |

### 抗性与免疫

- **抗性**：伤害减半后再与阈值比较。
- **免疫**：不受该类型伤害。
- 多个抗性来源只算一次。
- 先应用抗性/免疫，再标记护甲槽。

### 关键成功与伤害

- 攻击掷骰关键成功时：先取伤害骰最大值，再正常掷一次伤害骰，相加后加调整值。
- 例：2d6+1关键成功 → 12 + 2d6 + 1

---

## 反应掷骰

- 对攻击或危险的回应，使用二元骰。
- 不会产生希望、恐惧或额外GM行动。
- 其他角色不能帮助反应掷骰。
- 关键成功时无视附加效果（如伤害或压力）。

---

## 优势与劣势

| 术语 | 效果 |
|------|------|
| 优势 | 加1个d6优势骰到掷骰结果 |
| 劣势 | 减1个d6劣势骰从掷骰结果 |
| 抵消规则 | 同时有优势和劣势则相互抵消 |

**敌人优势/劣势**：额外掷一个d20，取高（优势）或低（劣势）。

## 与敌人战斗

### 战斗流程

- 玩家轮流聚焦行动，直到有人掷出恐惧结果、失败，或GM花费恐惧点打断。
- GM轮次：聚焦敌人执行动作（攻击、移动、清除状态等）。

### 距离系统

| 距离 | 范围 | 描述 |
|------|------|------|
| 近战 | 触手可及 | 几英尺内 |
| 邻近 | 5-10英尺 | 几乎可立即接触 |
| 近距离 | 10-30英尺 | 同一房间 |
| 远距离 | 30-100英尺 | 小型战场 |
| 极远 | 100-300英尺 | 战场远端 |
| 超出 | 300英尺+ | 无法成为目标 |

### 移动规则

- **动作中近距离移动**：作为动作一部分移动至近距离范围。
- **远距离移动**：需成功敏捷掷骰。
- **敌人移动**：通常可移动至近距离作为动作一部分。

### 掩护、视线与黑暗

- **掩护**：敌人攻击掷骰具劣势。
- **视线**：必须能看到目标。
- **黑暗**：GM可提高难度或施加劣势。

## 状态

### 三种基础状态

| 状态 | 效果 |
|------|------|
| 隐藏 | 所有以你为目标的掷骰具劣势。攻击后或进入视线则解除。 |
| 束缚 | 无法移动，但仍可执行动作。 |
| 脆弱 | 所有以你为目标的掷骰具优势。 |

### 解除状态

- 临时状态：可通过动作掷骰解除（GM设定难度）。
- 敌人：GM可用行动聚焦敌人解除状态。
- 特殊状态：需满足特定条件。

## 休整

### 短休（约1小时）

- 每位玩家选择**2项**休整行动。
- GM获得**1d4**恐惧点。
- 两次长休之间最多3次短休。

### 长休（数小时）

- 每位玩家选择**2项**休整行动。
- GM获得**1d4 + 玩家人数**恐惧点。
- 推进一个长期倒计时。

### 休整行动表

| 行动 | 短休效果 | 长休效果 |
|------|----------|----------|
| 处理伤口 | 恢复1d4+位阶生命点 | 恢复所有生命点 |
| 缓解压力 | 清除1d4+位阶压力点 | 清除所有压力点 |
| 修理护甲 | 清除1d4+位阶护甲槽 | 清除所有护甲槽 |
| 做好准备 | 获得1希望点（团队则2） | 获得1希望点（团队则2） |
| 推进项目 | - | 推进长期项目倒计时 |

### 休整时刷新特性

- "每次休息一次"特性在短休或长休后刷新。
- "每次长休一次"特性仅在长休后刷新。
- "每场游戏一次"特性在下一场游戏开始时刷新。

## 死亡

### 死亡行动（标记最后一个生命点时）

| 选项 | 效果 |
|------|------|
| **光荣就义** | 接受死亡，执行一次视为关键成功的行动，角色离世。 |
| **回避死亡** | 免于一死但陷入昏迷，局势恶化。掷希望骰，≤等级则获得一道伤痕。 |
| **孤注一掷** | 掷二元骰决定生死。希望高→恢复生命/清压力；恐惧高→死亡；关键成功→全恢复。 |

### 伤痕

- 划掉一个希望槽（永久失效）。
- 叙事效果自定（肉体疤痕、心理创伤等）。
- 划掉最后一个希望槽 → 角色旅程终结，需退役。

### 复活

- 10级辉耀法术"亡者苏生"可复活。
- GM也可提供其他复活途径（任务、仪式等）。

## 附加规则

| 规则 | 说明 |
|------|------|
| 向上取整 | 所有取整操作向上取整 |
| 重骰 | 必须接受新结果 |
| 承受伤害 | 受伤害时可标记希望点/压力点减伤 |
| 同时效果 | 控制方可任意顺序应用 |
| 持续法术 | 即使卡牌移出配置仍持续 |
| 花费资源 | 花费后即失去，除非特性允许 |
| 场景结束 | 由GM判断当前叙事情境结束 |

---

## 玩家最佳实践

1. **拥抱危险** – 让角色置身险境，创造精彩故事。
2. **善用资源** – 积极花费希望点，管理压力、生命、护甲槽。
3. **以故事为核心** – 协作叙事，主动带入主题和情感。
4. **逐步探索角色** – 在游戏中逐渐发现和塑造角色。

| 5级 | +1经历(+2)，熟练值+1，清除属性标记 |

### 升级选项（每升一级选择）

| 选项 | 效果 | 备注 |
|------|------|------|
| 增加2个属性 | 两个未标记属性永久+1 | 标记属性 |
| 增加生命槽 | 永久+1生命槽 | 加深虚线框 |
| 增加压力槽 | 永久+1压力槽 | 加深虚线框 |
| 提升经历 | 两项经历各+1 | - |
| 获得领域卡 | 从可用领域选≤当前等级卡牌 | - |
| 增加闪避值 | 永久+1闪避 | - |
| 子职业进阶/精通 | 获得下一张子职业卡 | - |
| 增加熟练值 | 熟练+1，伤害骰+1 | 需2个槽位 |
| 兼职 | 获得另一职业领域和基础卡 | 需2个槽位，5级起 |

### 兼职规则

- 5级起可选择兼职。
- 需占用**2个升级槽位**。
- 获得另一职业的一个领域（不能与已有领域重复）。
- 获得该职业的基础子职业卡（如带施法属性则可用）。
- 从新领域选择卡牌时，等级限制为当前等级一半（向上取整）。
- 使用该职业特性的效果等级与自身当前等级相同。
- 兼职后不能再获得原职业的精通卡牌，也不能再次兼职。

### 伤害阈值提升

每次升级后，将角色的伤害阈值永久提高1（因等级增加）。
