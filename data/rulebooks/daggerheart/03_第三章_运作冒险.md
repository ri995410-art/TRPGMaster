# 第三章：运作冒险

**本章仅供游戏主持人（GM）阅读**，包含主持《匕首之心》游戏所需的所有工具、机制和指引。

---

## 引言

作为GM，你负责引导剧情、扮演世界和NPC、裁决规则。本章提供：
- 游戏主持人准则
- 核心GM机制（骰子、行动、恐惧点）
- 设定难度与给予优势/劣势
- 敌人与环境操控
- 第零场与安全工具
- 运作单场游戏与战役

---

## 游戏主持人准则（7条）

1. **以虚构为始，以虚构为终** – 叙事驱动机制，机制回馈叙事。
2. **始终保持合作，冲突期间尤甚** – 与玩家是合作伙伴，不是对手。
3. **让世界充满生机、奇迹与危险** – 呈现动态、丰富的世界。
4. **提出问题并融入答案** – 与玩家共同构建世界，接受他们的创意。
5. **让每一次掷骰都至关重要** – 只在有意义的时刻要求掷骰。
6. **玩下去，看看会发生什么** – 预留惊喜空间，不要预设固定剧情。
7. **轻抓故事脉络** – 允许自己犯错和调整，保持叙事灵活。

## 游戏主持人最佳实践

| 实践 | 说明 |
|------|------|
| 营造充满好奇的游戏氛围 | 抛出线索和谜团，让玩家探索 |
| 赢得玩家的信任 | 兑现承诺，承认错误，设定明确预期 |
| 推动故事发展 | 每次掷骰后故事都要前进，即使失败 |
| 切入精彩时刻 | 跳过无聊部分，直接进入紧张场景 |
| 帮助玩家掌握机制 | 主动提示规则和能力 |
| 创建场外交流机制 | 鼓励玩家脱离角色讨论 |
| 告诉玩家角色该知道的信息 | 不要隐藏角色理应注意的细节 |
| 以动机赋予世界真实感 | 每个NPC和敌人都应有目标 |
| 让游戏机制鲜活起来 | 用机制增强叙事，用叙事解释机制 |
| 重构而非否定 | 玩家提议不合理时，协作调整而非直接拒绝 |
| 运用"片段"与"蒙太奇" | 重要时刻细描，平淡过程快进 |

## 应避免的误区

| 误区 | 解决建议 |
|------|----------|
| 削弱英雄作用 | 失败归因于环境/对手而非角色无能 |
| 总是告诉玩家掷什么骰 | 让玩家自主选择属性和方法 |
| 场景节奏拖沓 | 适时切场或引入新冲突 |
| 唯一解思维 | 接受玩家提出的替代方案 |
| 过度预设剧情 | 准备情境而非剧本，接受即兴 |
| 囤积恐惧点 | 主动花费恐惧点制造紧张感 |

## 核心GM机制

### GM的骰子

- 使用**单颗d20**（而非玩家的2d12）。
- 攻击掷骰：d20 + 攻击调整值 ≥ 玩家闪避值 → 命中。
- GM的关键成功：d20掷出20 → 自动成功 + 额外伤害（取伤害骰最大值 + 正常掷骰）。

### 判定动作掷骰

GM在玩家行动时决定是否需要掷骰，并告知：
1. **允许以代价保证成功** – 如"可以自动跳过，但会被发现"。
2. **明确风险和收益** – 告知成功和失败分别会发生什么。
3. **说明不可避免的代价** – 即使成功也会发生的情况（如屋顶坍塌）。

### 经历影响叙事

- 若玩家经历与行动高度匹配，且无重大危险，可允许自动成功。
- 困难情况下，可允许玩家标记压力换取自动成功。

## 游戏主持人行动

### 何时执行

| 触发条件 | 说明 |
|----------|------|
| 玩家掷出恐惧结果 | 包括恐惧成功和恐惧失败 |
| 动作掷骰失败 | 包括希望失败和恐惧失败 |
| 玩家做出有后果的行为 | 如冲入火场、挑衅强敌 |
| 玩家给出绝佳叙事机会 | 如说出戏剧性台词或做出鲁莽举动 |
| 玩家看向你等待发展 | 场景停滞时需要推动 |

### 行动类型（温和→强硬）

| 温和行动 | 强硬行动 |
|----------|----------|
| 展示世界的反应 | 迫使队伍分散 |
| 提出问题并基于回答继续 | 应用附带伤害 |
| 让NPC依据动机行动 | 清除临时状态或效果 |
| 暗示即将发生的隐藏威胁 | 改变环境 |
| 揭示不快的真相或意想不到的危险 | 聚焦一个敌人 |
| 利用角色目标驱使其行动 | 夺走重要的人或物 |
| 让玩家角色标记压力点 | 利用玩家背景对付他们 |
| 进行角色未察觉的行动 | 永久剥夺一次机会 |

### 处理动作掷骰快速参考

| 结果 | 回应短语 |
|------|----------|
| 希望成功 | "是的，并且..."（成功 + 希望点） |
| 恐惧成功 | "是的，但是..."（成功 + 代价，GM获恐惧点） |
| 希望失败 | "不，但是..."（失败 + 希望点） |
| 恐惧失败 | "不，并且..."（失败 + 严重代价，GM获恐惧点） |

## 恐惧点

### 获得恐惧点

| 来源 | 数量 |
|------|------|
| 战役开始时 | 等于玩家角色数量 |
| 玩家掷出恐惧结果（每次） | +1 |
| 短休 | +1d4 |
| 长休 | +1d4 + 玩家人数 |
| 某些特性/法术 | 按规则 |
| 上限 | 12点（场次间保留） |

### 花费恐惧点

| 用途 | 花费 |
|------|------|
| 打断玩家执行一个GM行动 | 1 |
| 在GM轮次执行额外GM行动 | 1 |
| 使用敌人的恐惧特性 | 标注数量 |
| 使用环境的恐惧特性 | 标注数量 |
| 将敌人经历加值加入一次掷骰 | 1 |

### 场景花费建议

| 场景类型 | 建议花费 |
|----------|----------|
| 日常场景（交流、补给） | 0-1 |
| 次要场景（随机事件、小遭遇） | 1-3 |
| 标准场景（关键战斗、危险旅程） | 2-4 |
| 主要场景（领袖战、转折点） | 4-8 |
| 高潮场景（最终决战、史诗时刻） | 6-12 |

### 如何处理大量恐惧点

- **先发制人**：开场立即花费1打断玩家，聚焦敌人。
- **持续花费**：每次GM轮次都花费额外恐惧点执行更多行动。
- **强势开场**：第一个GM轮次花费足够多恐惧点聚焦大部分敌人。
- **血战到底**：持续花费1聚焦其他敌人，直到攻击命中。

### 即兴恐惧行动

当需要更强硬的行动时，GM可即兴执行恐惧行动：
- 引入新敌人（即使无铺垫）
- 敌人发动强力法术或变身
- 环境施加强烈负面影响

## 给予优势与劣势

- GM可根据叙事给予玩家优势或劣势（加/减d6）。
- 非玩家角色优势/劣势：额外d20取高/低。
- 优势与难度取舍：优先用优势/劣势而非调整难度，因为更具叙事感。

## 敌人掷骰

### 敌人攻击掷骰

1. 掷d20 + 攻击调整值。
2. 可花费1恐惧点添加经历加值。
3. 结果 ≥ 玩家闪避值 → 命中。
4. 命中则掷伤害骰。

### 敌人反应掷骰

- 玩家能力迫使敌人反应时，GM掷d20。
- 可花费1恐惧点添加经历加值。
- 结果 ≥ 难度 → 成功。

### 敌人非攻击行动

- 敌人也可撬锁、攀爬等，但通常无需掷骰，由GM裁定。
- 若需掷骰，可花费恐惧点并掷d20。

## 职业希望特性

每个职业的希望特性（花费3希望点）应在触发时产生显著叙事影响。GM应鼓励玩家描述这些时刻的英雄壮举。

## 倒计时

### 标准倒计时

- 设定初始值（如"倒计时4"）。
- 每次玩家动作掷骰减少1（无论结果）。
- 降至0时触发效果。

### 动态倒计时

| 掷骰结果 | 进度倒计时（玩家期望） | 后果倒计时（玩家避免） |
|----------|------------------------|------------------------|
| 恐惧失败 | 不推进 | -3 |
| 希望失败 | 不推进 | -2 |
| 恐惧成功 | -1 | -1 |
| 希望成功 | -2 | 不推进 |
| 关键成功 | -3 | 不推进 |

### 进阶倒计时特性

| 特性 | 说明 |
|------|------|
| 随机起始值 | 掷骰确定起始值（如"倒计时1d6"） |
| 循环 | 触发后重置为起始值重新开始 |
| 递增 | 每次重置起始值+1 |
| 递减 | 每次重置起始值-1，降至0触发重大事件 |

### 长期倒计时

- 追踪跨多场游戏的宏大事件。
- 短休推进1次，长休推进2次。
- 用进度条记录（4-12格），每个格子可标注征兆事件。

### 追逐倒计时

- 追击方和逃脱方各设一个倒计时。
- 玩家成功掷骰推进己方倒计时；失败或恐惧成功推进对方倒计时。

## 扮演非玩家角色（NPC）

### 简化NPC创作

- 只需三要素：**名字**、**描述**、**动机**。
- 需要掷骰时直接设定难度，无需完整数据块。

### NPC盟友

- 战斗中无需完整数据块，聚焦其行动对剧情的推动。
- NPC盟友的帮助可让玩家动作掷骰获得优势。
- NPC可受伤或死亡，由GM根据剧情裁定。

### NPC特性

重要NPC可拥有特性，格式为"触发 → 效果"。示例：

**休想得逞**
- 触发：邻近范围内玩家角色至少标记2生命点。
- 效果：掷1d8，若≥4则NPC移动到该角色近战范围，代替标记1生命点。之后骰子降一级，直至无法使用。

**额外NPC特性示例**：
- **箭雨**：战斗开始启动循环倒计时，失败攻击时推进，触发时射箭造成伤害。
- **导师**：战斗开始时选学徒，学徒攻击失败时给予指导使其下次攻击优势。
- **重整态势**：所有玩家护甲槽满时传送至选定地点并清1护甲槽。
- **融入夜色**：长休时掷1d4，≤2则偷走金币后消失。

## 可选GM机制

### 命运掷骰

- GM让玩家只掷希望骰或恐惧骰来决定运气结果。
- 不产生希望/恐惧点，仅用于决定叙事走向。

### 坠落与碰撞伤害

| 坠落高度 | 伤害 |
|----------|------|
| 邻近范围 | 1d10+3物理 |
| 近距离范围 | 1d20+5物理 |
| 远距离/极远 | 1d100+15物理或即死 |

### 水下移动与战斗

- 攻击掷骰通常劣势（除非适应水下）。
- 无法水下呼吸者用倒计时（起始3+）追踪憋气；每次动作-1，恐惧结果额外-1，倒计时结束则每次行动标记1压力。

### 玩家角色间冲突

- 协商解决优先。
- 若必须掷骰：攻击掷骰对抗目标闪避；其他动作掷骰对抗反应掷骰，发起方总值需超过承受方。

## 第零场与安全工具

### 第零场目的

- 讨论战役概念、基调、目标、主题。
- 创建角色。
- 建立安全工具。

### CATS框架

| 要素 | 内容 |
|------|------|
| 概念 (Concept) | 战役核心设定（如"儿时伙伴重聚发现秘密"） |
| 目标 (Aim) | 创意和社交期望（如"每周战役，侧重角色发展"） |
| 基调 (Tone) | 情感基调和叙事倾向（圈选/划掉形容词） |
| 主题 (Subject) | 希望重点呈现和需要回避的内容 |

### 安全工具

**界线与帷幕**：
- 界线：完全不希望出现的内容（绝对禁止）。
- 帷幕：可存在但不详细描写。

**X卡**：
- 任何玩家（包括GM）可轻触X卡或做X手势。
- 指出希望"回溯"的游戏节点，移除某内容。
- 可说明移除原因（非强制）。

### 第零场流程示例（4小时）

| 时段 | 时长 | 活动 |
|------|------|------|
| 玩家介绍 | 5-10分钟 | 互相认识 |
| 第零场概述 | 5-10分钟 | 说明流程 |
| CATS讨论 | 40分钟 | 概念/目标/基调/主题 |
| 休息 | 5-10分钟 | 放松 |
| 世界构建 | 50分钟 | 共同创造或引入已有设定 |
| 休息 | 5-10分钟 | 恢复精力 |
| 角色创建 | 70分钟 | 引导完成所有步骤 |
| 休息 | 5分钟 | 准备 |
| 引入场景（可选） | 30分钟 | 开始简短冒险 |
| 总结与反馈 | 10分钟 | 收集问题与调整 |

## 运作一场游戏

### 思考叙事节奏

- 节奏 = 改变故事轨迹的瞬间。
- GM和玩家轮流制造节奏。
- 用"节奏思维"准备倒计时和事件链。

### 准备战斗遭遇

#### 叙事功能
- 战斗应服务于故事：展现反派、揭示信息、推进角色弧光。

#### 敌方动机
- 敌人何时投降？逃跑？除生存外还有什么目标？

#### 动态环境
- 敌人如何利用环境优势？
- 环境如何强化叙事目标？

#### 飞行及其他特性
- 考虑玩家能力，设计相应挑战。

### 战斗叙事范例

- 示例：腐化土元素控制树精攻击队伍，树精被附身但不知情，队伍可通过调查发现真相。

### 游戏奖励

- 主要奖励：信息。
- 战利品：在章节结束或剧情节点给予。
- 角色应在进入新位阶的前几个等级获得匹配装备。

### 构筑场景

- 调动五感描述（视觉、气味、触觉、声音、味觉）。
- 提供足够细节让玩家做出决策。

### 分享聚光灯

- 轮转聚焦，主动询问安静玩家。
- 使用视觉辅助（如动作追踪器）。
- 鼓励玩家间互动。

### 运用冲突

- 外部冲突（对抗敌人） + 内部冲突（情感挣扎） = 精彩角色弧光。

#### 社交冲突
- 非敌意NPC：协作过程。
- 高难度社交：用压力槽代表NPC耐心（如5压力槽，填满则让步）。
- 社交倒计时：代表NPC耐心耗尽。

#### 社交冲突示例
- 贵族有5压力槽，队伍通过论证、魅惑、经济说服逐步填满，最终说服其出兵。

### 武装冲突

#### 为战斗赋予层次化目标
- 目标不止"杀光敌人"：获取、俘虏、启动装置、阻止仪式、坚守阵地等。
- 随机目标表（1d12）：获取、俘虏、启动、嫁祸、逼入死角、阻止仪式、坚守、安放证据、占领、骚扰、摧毁、调查。

#### 使用恐惧点制造戏剧张力
- 即使玩家连续成功，也可花费1恐惧点打断。

### 分阶段战斗

| 变化类型 | 示例 |
|----------|------|
| 改变交战条件 | 战斗转为追逐战 |
| 改变战场 | 暴风雪、坍塌、传送 |
| 改变敌人 | 敌人变身、分裂、恢复生命 |

### 使用休整

- 让玩家主导休整场景。
- **休整期项目**：用进展倒计时追踪，每次推进倒计时减少。失败也能有进展（减少1）。
- **GM休整**：短休获1d4恐惧点，长休获1d4+玩家人数恐惧点并推进长期倒计时。

### 延长休整时间

- 快进数天，每名角色选择一个目标。
- GM获得1d6恐惧点，推进长期倒计时。

### 角色死亡

#### 选择死亡行动

| 选项 | GM角色 |
|------|--------|
| 光荣就义 | 与玩家协作决定关键成功的行动，不破坏故事 |
| 回避死亡 | 角色昏迷，局势恶化，可能获得伤痕。若划掉最后希望槽则必须退役 |
| 孤注一掷 | 基本无法干预；希望→生还，恐惧→死亡 |

#### 灾难将临（团灭风险）

- 与玩家沟通：接受团灭吗？撤退吗？
- 考虑敌人动机（杀、抓、赶走？）
- 若玩家不想团灭，可引入救援（盟友、神祇、自然之灵等）。
- 若全体同意团灭，则结束该队故事，创建新角色继续战役。

### 引入新角色

- 新角色等级与队伍当前等级相同。
- 可跳过常规关联问题，使用以下提问：
  - "你掌握着队伍所需的重要信息。是什么？"
  - "你正身陷险境，急需帮助。什么在追踪你？"
  - "你非常了解队伍中的某个人，一直在寻找他。你们上次见面发生了什么？"
  - "你的上一支冒险队伍覆灭了。什么导致覆灭？"
  - "你曾隶属敌对阵营，现在想结盟。为什么转变？"
  - "你受托将一件失物交给队伍成员。是什么？"

### 提升队伍等级

- 通常在一章结束时升级。
- 每2-4场游戏一次（短战役可加速）。
- 所有玩家同步升级，按角色指南选择选项。

## 运作单场游戏

### 单场游戏构建（填空式）

**序言**：从选项中填空，创建故事开端。

```
我们的故事发生在 (1) 王国境内。我们目前正穿越 (2)，它最出名的是 (3) 以及围绕着它的 (4)。
(1) 阿泰拉|贝尔颂|海姆伦德|鲁马里|冬日之阳|柳溪谷
(2) 阿特拉斯|黎明谷|靛蓝之影|拉思迈尔|奇迹之地
(3) 其巨大的尖塔|其神圣的结界|一颗巨大的树|维持其漂浮的神秘力量|隐藏其踪迹的微光
(4) 酷热的沙漠|幽暗的森林|茂密的丛林|高耸的山脉
```

**冒险**：

```
昨晚的 (1) 之后，这里有许多人 (2)。今天早上，我们发现昨夜发生的事情 (3)。
为了解决这个问题，我们需要 (4)。
故事就在这里展开：我们准备出发前往 (5)。
(1) 严重的火灾|被某个部落袭击|可怕的风暴|女王被刺杀
(2) 身受重伤|决定离开|陷入了可怕的诅咒|发动了起义
(3) 让我们在乎的人命悬一线|摧毁了城镇的保护符文|唤醒了一群亡灵|激怒了一头古老的野兽
(4) 寻找一件强大的月之石遗物|带回卡瑞克斯魔导师|向众神之家献上贡品|请求一位狡诈仙灵的帮助
(5) 海尔高塔群|破碎之海|旅人终点|荒远镇|王国的都城|高地之巅
```

**GM准备**：

```
一旦队伍离开城镇，他们发现 (1)。
当队伍朝目的地前进时，他们 (2)。
当队伍抵达目标地点时，他们发现 (3)。
当队伍终于找到他们要找的东西时，他们得知：(4)。
(1) 昨晚事件的残留痕迹|某种狂野而危险的事物|一个关于目的地的不祥警告|他们正被人跟踪
(2) 他们发现了之前遗漏的重要之物|一个出人意料的盟友加入他们|一处危险的障碍挡住了去路|他们无意中闯入了某个危险生物的领地
(3) 目标被隐藏或设有重重保护|有人赶来拦截他们|此地出乎意料地危险|有人早就等着他们
(4) 也有人在寻找这个目标|它并不如他们所预期的那样|他们还需要其他东西才能成功|完成目标将使他人陷入危险
```

- 将玩家背景与这些选项关联。
- 准备简单敌人和地图即可开始。

## 运作一场战役

### 选择战役框架

可使用第五章提供的六个框架，或自行创作。

### 构建地图

- 使用附录空白地图或框架地图。
- 第零场让玩家添加地点。
- 保留空白区域供以后探索。

### 融入玩家背景故事

- 记录每个角色的关键叙事要素（背景问题答案）。
- 寻找关联点，编织成故事线。

示例角色背景记录：
- 玛丽戈尔德：精灵游侠，来自漂浮之城，被元素领袖追捕。
- 巴纳巴斯：法师，追寻巨龙克鲁萨尔的獠牙，与马弗里克是宿敌。
- 贾斯珀：吟游诗人，与公主阿斯特丽德有秘密恋情。
- 斯普劳特：德鲁伊，无意中破坏环境被驱逐。

将这些线索相互关联，形成战役主线。

### 规划故事篇章（三幕式）

**第一幕：冲突**
- 引入无法忽视的问题，引出更大冲突。
- 节奏点示例：队伍遭遇活动植物袭击 → 发现亚罗法师被胁迫 → 揭开马弗里克阴谋。

**第二幕：复杂局势**
- 玩家踏上寻求答案之旅，遇到层层阻碍。
- 阻碍应紧扣角色背景和主题（如巨龙克鲁萨尔的踪迹、腐化诅咒等）。

**第三幕：高潮**
- 揭开重大谜题，与强敌决战。
- 可设置反转或意外。
- 终局后为下一篇章埋下伏笔。

### 构建故事篇章（麻绳比喻）

- A线：故事主轴（核心行动）
- B线：灵活支线（干扰A线）
- C线：暗线（埋设后续伏笔）

示例表格（三幕式篇章）：
| 篇章 | 场次 | A线 | B线 | C线 |
|------|------|-----|-----|-----|
| 1 | 1-3 | 马弗里克阴谋 | 元素生物追猎 | 亚罗被控 |
| 2 | 4-6 | 追查亚罗 | 巨龙克鲁萨尔 | 斯普劳特的诅咒 |
| ... | ... | ... | ... | ... |
