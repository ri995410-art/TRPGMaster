# 第四章：敌人与环境

本章包含所有敌人数据块和环境数据块，供GM在游戏中使用。

---

## 使用敌人

### 敌人数据块拆解

| 要素 | 说明 |
|------|------|
| 名称 | 敌人独特名称 |
| 位阶 | 1-4，对应玩家位阶 |
| 类型 | 斗士/集群/头目/杂兵/远程/潜伏/社交/独狼/标准/辅助 |
| 描述 | 外观和举止描述 |
| 动机与战术 | 行为目标和策略建议 |
| 难度 | 对抗掷骰目标值 |
| 阈值 | 重度/严重伤害阈值 |
| 生命点 | 承受伤害能力 |
| 压力点 | 可消耗资源 |
| 攻击调整值 | 攻击掷骰加值 |
| 普通攻击 | 名称、距离、伤害 |
| 经历 | 特定情境加值（GM可花费恐惧点使用） |
| 特性 | 被动/动作/反应 |

### 敌人类型

| 类型 | 描述 | 花费（战斗点数） |
|------|------|------------------|
| 斗士 | 强韧且攻击力强大 | 4 |
| 集群 | 多只相同生物协同 | 2 |
| 头目 | 指挥并召唤其他敌人 | 3 |
| 杂兵 | 容易击败，数量多时危险 | 1（=队伍规模） |
| 远程 | 远处高伤害攻击 | 2 |
| 潜伏 | 机动性强，伏击对手 | 2 |
| 社交 | 通过对话应对 | 1 |
| 独狼 | 对整个队伍构成强大挑战 | 5 |
| 标准 | 普通敌人 | 2 |
| 辅助 | 增强盟友，扰乱对手 | 1 |

### 战斗点数系统

**基础公式：** (3 × 玩家角色数量) + 2

**调整：**
- 更简单/更短：-1
- 使用2个以上独狼：-2
- 所有敌人伤害+1d4（或固定+2）：-2
- 使用低位阶敌人：+1
- 不使用斗士/集群/头目/独狼：+1
- 更危险/更长：+2

### 敌人特性类型

| 类型 | 说明 |
|------|------|
| 被动 | 始终生效 |
| 动作 | 需聚焦使用时生效 |
| 反应 | 满足触发条件时生效 |
| 恐惧特性 | 需花费恐惧点，强力效果 |

### 敌人关键特性解释

| 特性 | 说明 |
|------|------|
| 集群 Horde (X) | 标记一半生命点后，普通攻击改为造成X伤害 |
| 杂兵 Minion (X) | 受任何伤害即被击败；每造成X伤害额外击败一个 |
| 无情 Relentless (X) | 每个GM轮次可被聚焦X次 |
| 迟缓 Slow | 第一次被聚焦时无法行动，需第二次聚焦才能行动 |

#### 酸液掘地者 ACID BURROWER
**位阶1 独狼**

马匹大小的昆虫，掘地利爪与酸性血液。

| 数据 | 值 |
|------|-----|
| 难度 | 14 |
| 阈值 | 8/15 |
| 生命点 | 8 |
| 压力点 | 3 |
| 攻击调整值 | +3 |
| 普通攻击 | 爪击：邻近 1d12+2 物理 |
| 经历 | 震动感知 +2 |

**特性：**
- **无情 Relentless (3)**：每个GM轮次可聚焦3次。
- **破土而出**（动作）：标记1压力，邻近范围所有生物必须敏捷反应，否则被击倒并脆弱。
- **喷吐酸液**（动作）：前方近距离范围攻击，目标必须标记1护甲槽（无效用），否则额外标记1生命。
- **酸液沐浴**（反应）：受到严重伤害时，邻近范围生物受1d10物理，地面被酸覆盖。
