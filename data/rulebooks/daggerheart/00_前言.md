# 引言

## 游戏概述

- **名称**：匕首之心 (Daggerheart)  
- **类型**：奇幻角色扮演合作游戏 (TTRPG)  
- **人数**：2-5名玩家 + 1名游戏主持人（GM）  
- **核心骰子**：玩家使用两颗 d12（希望骰和恐惧骰），GM使用一颗 d20。  
- **设计理念**：虚构优先、协作叙事、战斗流畅无回合制。  

## 核心术语

| 术语 | 解释 |
|------|------|
| 场次 (Session) | 一次游戏聚会，完成一个小故事。 |
| 战役 (Campaign) | 多场次组成的连贯叙事。 |
| 篇章 (Arc) | 战役中的一段故事弧。 |
| 单场游戏 (One-shot) | 一次性短冒险。 |
| 玩家角色 (PC) | 由玩家扮演的角色。 |
| 非玩家角色 (NPC) | 由GM扮演的角色。 |
| 游戏主持人 (GM) | 负责世界、NPC、裁决。 |

## 黄金法则

> **创作属于自己的世界。规则是辅助，不是枷锁。在大家同意下可调整一切。**

## 裁定大于规则

- 当规则与叙事冲突时，以叙事和玩家体验为准。
- GM拥有最终裁定权。

# 第一章：准备冒险

本章包含世界背景、角色创建全流程。

## 世界概览

### 核心界域

1. **凡人界域**：物质位面，大多数冒险发生地。由失落诸神创造，现为失落诸神囚禁地。弱等神祇栖居于此。
2. **圣辉上界**：众神领域，现由新神占据。神祇离开需付出代价。
3. **轮回下界**：失落诸神流放地，腐化与恶魔之地。
4. **其他界域**：元素大陆、星界、死亡谷等。

### 魔法与法术

- 魔法无处不在，既可内在也可外在。
- 拥有施法属性的角色才能施法。
- 可进行“风格化调整”以适应角色设定（无机制改变）。

### 第三步：分配角色属性

**六项属性**：
- 敏捷 (Agility)：冲刺、跳跃、机动
- 力量 (Strength)：举起、猛击、擒抱
- 灵巧 (Dexterity)：控制、隐藏、修补
- 本能 (Instinct)：感知、察觉、导航
- 风度 (Presence)：魅力、表演、欺瞒
- 知识 (Knowledge)：回想、分析、理解

**起始调整值**（自由分配）：+2, +1, +1, 0, 0, -1

属性调整值用于动作掷骰，负值则减去。

---

### 第四步：记录角色其它信息

- **闪避值**：从职业获得，可后续提升。
- **生命点**：职业初始值，可升级增加。
- **压力点**：所有职业初始6点，可升级增加。
- **希望点**：初始2点，上限6点（每场之间保留）。
- **恐惧点**：GM管理，玩家掷出恐惧结果时GM获得。

### 第六步：创作背景

- 回答角色指引中的背景问题（如“谁教会你自信？”等）

### 第七步：创作经历

- 初始2个经历，每个+2加值。
- 经历是描述角色专长的短语（如“刺客”、“谈判专家”）。
- 使用经历：花费1希望点，将经历加值加入动作或反应掷骰。
- 可同时使用多个经历（各花费1希望点）。
- 可随时与GM协商修改经历。

**经历范例**（供参考）：
- 背景类：刺客、铁匠、赏金猎人、海盗、学者、士兵、盗贼
- 性格类：和蔼可亲、胆小鬼、广交朋友、孤狼、忠诚
- 专长类：杂技演员、治疗者、发明家、制图师、神枪手
- 技能类：动物语者、谈判者、快手、追踪者
- 短语类：抓不到我、初学者的运气、知识就是力量

## 职业详解（含子职业、特性、进阶、精通）

由于内容较多，此处先列出每个职业的核心机制，详细领域卡牌在附录中统一列出。

### 吟游诗人

- **领域**：优雅、典籍
- **希望特性**：大闹一场（干扰目标，难度降低2）
- **职业特性**：鼓舞人心（每场一次，给所有盟友鼓舞骰d6，5级升d8）
- **子职业**：
  - **游唱乐手**：天赋艺者（演奏三首曲目：舒缓回血、史诗致脆弱、悲凉得希望），进阶首席乐师（鼓舞时盟友得希望或清压力），精通乐坛泰斗（长休后每曲可奏两次）
  - **言文巧匠**：激昂演说（清2压力），诗人之心（社交掷骰后可花希望加d4），进阶口若悬河（鼓励盟友可选效果），精通史诗篇章（鼓舞骰变d10，帮助时掷d10优势）

### 德鲁伊

- **领域**：贤者、奥术
- **希望特性**：幻化成兽（变形无需压力，选属性+1）
- **职业特性**：野兽形态（标记压力变野兽，获得特性，可随时解除），荒野恩泽（自然小效果）
- **子职业**：
  - **元素结社**：元素化身（标记压力灌注火/土/水/风元素，获得不同增益），进阶元素灵气（休息一次，元素灵气影响近距离），精通元素主宰（更强增益）
  - **复兴结社**：自然澄澈（长休一次，创造宁静空间清压力），再生（花费3希望恢复1d4生命），进阶再生延伸（范围扩大）、守卫防护，精通动物守护（野兽形态下盟友受伤可压力减少其生命）

**野兽形态选项**（位阶1-4，详见野兽形态表）

### 守护者

- **领域**：勇气、利刃
- **希望特性**：前线铁壁（清除2护甲槽）
- **职业特性**：势不可挡（长休一次，获得威势骰d4，伤害时骰值增加，超过最大值结束，5级升d6；期间物理伤害降一级，加伤害骰，免疫束缚/脆弱）
- **子职业**：
  - **坚毅铁卫**：坚定不移（阈值+1），钢铁意志（可额外标记护甲槽降伤害），进阶威武不屈（阈值+2，并肩作战保护盟友），精通临危不惧（阈值+3，忠诚护卫替盟友承受伤害）
  - **复仇战卫**：从容应对（额外压力槽），复仇反击（成功攻击后压力反击），进阶报复一击（敌人伤盟友时下次攻击+1熟练），精通誓绝仇敌（花费2希望锁定目标，可交换骰子结果）

### 游侠

- **领域**：骸骨、贤者
- **希望特性**：压制众敌（攻击成功后额外攻击两个敌人）
- **职业特性**：游侠专注（花费1希望标记目标，获增益：知晓方位、目标标记压力、失败可结束并重骰）
- **子职业**：
  - **驯兽大师**：动物伙伴（获得伙伴表），进阶专家训练（额外伙伴升级）、战斗情谊（伙伴近战范围时闪避+2），精通高级训练（额外两个升级）、忠诚挚友（代替承受伤害）
  - **寻路斥候**：无情猎杀者（伤害骰可压力+1熟练，严重伤害时目标压力），前路明晰（确定最短路径），进阶狡猾猎杀者（专注目标闪避+2），精通顶级猎杀者（攻击前花希望，成功清GM恐惧点）

**动物伙伴**：独立伙伴表，初始闪避10，两个经历+2，攻击伤害1d6近战。伙伴受伤害时标记压力，满压力则退出场景直至长休。伙伴升级选项包括聪慧、黑暗中的光芒（额外希望槽）、动物抚慰、着甲、凶猛、坚韧、羁绊、警觉。

### 游荡者

- **领域**：午夜、优雅
- **希望特性**：闪身伎俩（闪避+2直到被命中或休息）
- **职业特性**：隐匿无踪（隐藏改为隐匿，保持静止不被看见），隐匿偷袭（隐匿或盟友近战时伤害额外位阶数个d6）
- **子职业**：
  - **黑夜行者**：阴影迷踪（压力在阴影间传送并隐匿），进阶黑暗云团（施法15创造黑暗云团）、肾上腺素（脆弱时等级加伤害），精通掠影疾行（闪避+1，传送更远）、遁入阴影（随时压力隐匿并解束缚）
  - **帮派豪杰**：交际达人（到达新地方认识人，选择事实），进阶神通广大（每场一次召唤联系人获取物品或加成），精通坚实后盾（每场三次，新增选项）

### 神使

- **领域**：辉耀、勇气
- **希望特性**：维生救援（近距离盟友恢复1生命）
- **职业特性**：虔信骰（每场开始掷施法属性个d4作为虔信骰，可帮助盟友减伤、加掷骰、得希望）
- **子职业**：
  - **神兵驭者**：灵魂武器（近战武器可飞出击打近距离敌人，压力可额外目标），怜悯之触（长休一次恢复2生命或清2压力），进阶坚定信仰（虔信骰多掷一骰弃低，怜悯之触两次），精通神圣共鸣（伤害骰相同则翻倍）
  - **翔翼哨兵**：辉光羽翼（飞行，可携带生物，花希望额外伤害），进阶空灵显像（飞行时风度优势，成功可清恐惧点），精通升华之身（严重阈值+4）、神恩之力（额外伤害变d12）

### 术士

- **领域**：奥术、午夜
- **希望特性**：无常魔法（重掷任意数量魔法伤害骰）
- **职业特性**：奥术感应（感知魔法），次级幻术（施法10创造幻象），引导原力（长休一次将领域卡入宝库，获得希望或增强法术）
- **子职业**：
  - **元素起源**：元素门徒（选元素，花希望获+2动作或+3伤害），进阶自然闪避（压力可加d6闪避），精通超凡化形（长休一次变身，选两项增益）
  - **原初起源**：操纵魔法（压力修改法术：扩大范围、+2动作、伤害骰翻倍、额外目标），进阶附魔援助（帮助施法时d8优势，长休可交换骰子），精通奥术充能（受魔法伤害或花希望充能，成功后加伤或难度）

### 战士

- **领域**：利刃、骸骨
- **希望特性**：绝不手软（攻击+1直到休息）
- **职业特性**：借机攻击（敌人离开近战范围时可反应，成功可选效果），战斗专训（无视负荷，物理伤害+等级）
- **子职业**：
  - **勇气呼唤**：勇气可嘉（恐惧失败获得希望），战斗仪式（长休一次，危险前准备清压力得希望），进阶迎难而上（生命≤2时d20作希望骰），精通战友之情（每场多一次接力，盟友只需2希望）
  - **屠戮呼唤**：无情杀手（获得杀手骰池，希望结果可存d6，攻击或伤害时使用），进阶武器专家（成功攻击可花希望加副手伤害，长休重掷1），精通战备训练（队伍获得战备训练休整行动，指导队友得杀手骰）

### 法师

- **领域**：典籍、辉耀
- **希望特性**：死期未至（迫使敌人重掷攻击或伤害骰）
- **职业特性**：魔法伎俩（无害小魔法效果），奇异规律（选1-12数字，掷出该数得希望或清压力，长休可改）
- **子职业**：
  - **知识学派**：准备就绪（额外领域卡），熟能生巧（经历可用压力代替希望，加值翻倍），进阶驾轻就熟（额外领域卡）、完美回想（休息时回想费用减1），精通炉火纯青（额外领域卡）、水滴石穿（经历掷d6，5+免费）
  - **战争学派**：战斗法师（额外生命槽），直面恐惧（恐惧成功额外1d10魔法），进阶召唤护盾（希望≥2时闪避+熟练）、惧为己有（额外伤害变2d10），精通趁火打劫（攻击成功可压力迫额外生命）、无所畏惧（额外伤害变3d10）
